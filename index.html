Setup

How to apply

▾
1
Install a Custom Launcher

Get Nova Launcher, Niagara or Lawnchair from the Play Store — all free.

2
Set It as Your Default Launcher

Tap the Home button — Android should ask which app to use. Pick your new launcher and tap Always. If it doesn't ask, go to Settings → Apps → Default apps → Home app and pick it there.

3
Download & Unzip the Icon Pack

Unzip the Complete Icon Pack to your phone storage using a file manager like Files by Google.

4
Apply the Wallpaper

Long-press the home screen → Wallpapers → choose the mobile wallpaper from your files.

5
Change Any App Icon

Long-press an app → Edit → tap the icon → Pick image → browse to your PNG.

💡 Best icon size for Android home screens: 128px or 256px.
1
Open the Shortcuts App

It's pre-installed on every iPhone. Search for it if you can't find it.

2
Create a New Shortcut

Tap + → Add Action → search Open App → choose the app.

3
Set Your Custom Icon

Tap ⋯ → Add to Home Screen → tap the icon → Choose Photo → select your PNG.

4
Apply the Wallpaper

Save the mobile_iPhone wallpaper to Photos → Settings → Wallpaper → Add New Wallpaper.

⚠️ iOS shows the Shortcuts app briefly when tapping a custom icon — an Apple restriction. Use 256px or 512px icons for sharpest results.
1
Find the App in Finder

Open Finder → Applications → locate the app you want to customize.

2
Open Get Info

Right-click the app → Get Info (or press ⌘I).

3
Replace the Icon

Click the small icon top-left of the Info window, then drag your PNG onto it (or copy/paste).

💡 Use 512px icons on Mac for crisp Retina display results.
1
Right-click a Shortcut

Right-click any desktop shortcut → Properties.

2
Change Icon

On the Shortcut tab click Change Icon → Browse.

3
Select Your Icon

Pick a .ico file (convert the PNG first if needed) → OK → Apply.

💡 Windows shortcuts need .ico format — convert the 256px PNGs with a free online converter.

Set any NMS animation as your lock screen wallpaper automatically every time you plug in. Works on Samsung via Modes & Routines. iPhone setup coming soon.

Android — Samsung Modes & Routines
1
Open Settings

Go to your phone's Settings app and scroll down to Modes and Routines.

2
Go to Routines → tap +

Select the Routines tab at the bottom, then tap + in the top right to create a new routine.

3
Set the trigger

Tap Add condition → Charging status → select Charging (tick both Wired and Wireless) → Done.

4
Set the action

Tap Add action → Change Lock screen wallpaper → browse to your NMS MP4 file and select it.

5
Optional: keep screen on

Add a second action: Always On Display → set to On / Always so the animation stays visible while charging.

6
Set duration & save

Set Keep routine until → Forever. Samsung automatically adds a "When routine ends" block that reverts your wallpaper when you unplug. Tap Done.

💡 The routine auto-reverts your normal lock screen the moment you unplug — no manual reset needed.
iPhone — Shortcuts + third-party app

iOS doesn't allow custom video lock screens natively. The workaround is a screen animation app from the App Store, triggered automatically by a Shortcuts automation when you plug in.

1
Get a screen animation app

Search the App Store for a charging animation or screen saver app that supports custom video or image import. Save your NMS MP4 (or a still frame) into the app.

2
Open the Shortcuts app

It's pre-installed on every iPhone. Tap the Automation tab at the bottom.

3
Create a new automation

Tap + → New Automation → scroll to Charger → select Is Connected → Next.

4
Add the action

Tap Add Action → search Open App → choose your animation app → Next.

5
Turn off the confirmation prompt

Disable Ask Before Running so the app opens automatically when you plug in → Done.

💡 On iOS 17+ you can also use StandBy mode — place your phone landscape while charging and it shows a full-screen customisable display automatically, no extra app needed.

Add an actual NMS-styled clock/date widget to your home screen using KWGT (free) and the Widget Kit download below — two transparent frames, both fonts (Orbitron + the NMS alien alphabet), and the exact colors to match.

▶ Get KWGT — Google Play (free)
1
Get the Widget Kit & install KWGT

Download Widget Kit from the Downloads section, and get KWGT Kustom Widget Maker free from the Play Store (button above).

2
Add a KWGT widget

Long-press your home screen → Widgets → drag KWGT onto the screen — its editor opens automatically.

3
Add the NMS frame

Tap + → Image → browse to the frame PNG from the Widget Kit (wide for clock+date, square for something compact).

4
Add clock & date text

Tap + → Text for each — set font to Orbitron (the .ttf is in the kit, since KWGT's own font search doesn't reliably find it), clock in white #EAF6FF, date in gold #F0A500.

💡 Full step-by-step — plus a real on/off Settings toggle for the NMS alien font, and how to export your finished widget as a reusable .kwgt file — is inside the Widget Kit zip.
⚠️ KWGT is Android-only — there's no direct iOS equivalent that works the same way (image + freely-placed text). iOS widget apps use Apple's own WidgetKit system instead.

Questions

FAQ

Is it really free?

Yes — every icon, wallpaper, animation and the font are free to download and use. No account, no paywall.

Do I need a special launcher?

On Android, a custom launcher (Nova, Niagara or Lawnchair) makes applying icons easiest. On iPhone you can use the built-in Shortcuts app — no extra app needed.

Will it work on iPhone?

Yes. iOS applies custom icons through Shortcuts. One Apple quirk: tapping a themed icon flashes the Shortcuts app for a moment before opening — that can't be bypassed.

What's the "install app" button?

This site is a PWA, so you can add it to your home screen and open it like a native app — it then works offline. On Android you'll get an install prompt; on iPhone use Share → Add to Home Screen.

Is this an official No Man's Sky product?

No. It's a free fan-made project inspired by the game's aesthetic and is not affiliated with or endorsed by Hello Games.
