🧩 NMS Widget Kit

Setup Guide

This kit gives you two transparent NMS-styled widget frames, the real Orbitron font file, and the exact colors/formulas to build a real home-screen widget with them using KWGT — a free, hugely popular widget-maker app for Android.

▶ Get KWGT — Google Play (free)
iOS note: KWGT is Android-only — Kustom Industries has never released an iOS version, and there's no direct equivalent app that works the same way (place an image + freely-positioned text on top). iOS widget apps like Widgetsmith or Color Widgets can make custom widgets, but through Apple's own WidgetKit system, which works differently from this guide. This kit is built for Android.

What's in this kit

  • nms_widget_frame_wide.png — a 1080×540 frame, sized for a clock + date widget
  • nms_widget_frame_square.png — a 540×540 frame, sized for something compact like battery, weather, or a single stat
  • Orbitron-Variable.ttf — the real font file, since it doesn't reliably show up in KWGT's own font search
  • This guide

Both frames are transparent — your phone wallpaper shows through them, so they'll look right on any background.

Importing the font: in KWGT, when setting a text layer's font, choose File as the source (not the built-in Google Fonts search) and browse to Orbitron-Variable.ttf from this kit. If the file picker can't see it, make sure it's been unzipped out of this kit's own .zip first (KWGT can't reach into a zip), and that KWGT has storage/file access permission (Android Settings → Apps → KWGT → Permissions).

Building the widget

1
Install KWGT

Get KWGT Kustom Widget Maker free from the Play Store (link above).

2
Add a KWGT widget

Long-press an empty spot on your home screen → Widgets → find KWGT → drag it onto your home screen. Its editor opens automatically.

3
Add the NMS frame as the background

Tap + → Image → Gallery → browse to wherever you unzipped this kit → pick nms_widget_frame_wide.png (or the square one for something compact). Drag the corner handles to resize the widget on your home screen.

4
Add the clock text

Tap + → Text. Tap the small fx formula icon and type $df("HH:mm")$ for 24-hour time (or $df("h:mm a")$ for 12-hour with AM/PM). Font: import Orbitron per the note above, color #EAF6FF. Center it in the upper-middle of the frame.

5
Add the date text

Tap + → Text again. Formula: $df("EEE MMM d")$ — add a galaxy name or any label you like after it, that's just plain text. Font: Orbitron, smaller size, color #F0A500. Place directly under the clock text.

6
Save

Tap the checkmark / back arrow. Your widget is done — resize or move it like any other Android widget.

Using the square frame instead

Same steps, just start from nms_widget_frame_square.png in Step 3. It's a better fit for a single stat, a short label, or a battery percentage — one bigger centered text box instead of a stacked clock+date pair.

🔁 Adding a simple on/off font toggle

Want an on/off switch to flip between Orbitron and the NMS alien font — no auto-cycling, no tap zone, just a real setting?

  1. Open the widget's Globals panel (top toolbar) → add a new Global → type Switch/Boolean, name it e.g. nmsFont.
  2. On each text layer, instead of picking a font directly, tap the fx icon next to the font field and enter a formula: $if(gv(nmsFont)=1,"kfile://.../nms-alphabet.ttf","kfile://.../Orbitron-Variable.ttf")$ (KWGT fills in the real file paths for you once each font's been added to the layer once).

The Global becomes a real switch in the widget's own Settings screen (long-press the widget → gear icon).

📤 Exporting your finished widget

Once it looks right, you can save it as a .kwgt file — either to reuse on another device, or to share:

  1. Open the widget in KWGT's editor
  2. Tap the menu (⋮ or the Kustom icon, depending on your KWGT version) → Export (sometimes labelled Save as preset or Share)
  3. Choose Export as .kwgt file — this saves a self-contained file with your layout, images and fonts all bundled in

That exported file is the real, KWGT-verified format — reliable to share or reinstall anywhere, unlike a hand-written one.
