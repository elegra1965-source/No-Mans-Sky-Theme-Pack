🤖 Android — Free Assignment (Recommended)

1
Install a Custom Launcher

Download one of these free apps from the Play Store: Nova Launcher (most popular), Niagara Launcher (minimal), or Lawnchair (free, open source).

2
Set It as Your Default Launcher

Press your phone's Home button — Android should ask which app to use as Home; select your new launcher and tap Always. Didn't get asked? Go to Settings → Apps → Default apps → Home app (wording varies by phone brand) and pick it there manually. You can always switch back the same way.

3
Apply the Wallpaper

Long-press your home screen → Wallpapers → My photos or Files → navigate to the wallpaper file and set it.

4
Change an App Icon

Long-press any app icon → Edit (pencil icon, appears in Nova/Niagara) → tap the current icon → Pick image or Custom icon → browse to the icon PNG → Done ✅

5
Repeat for Each App

Assign any icon to any app — mix and match however you like!

Tip: Use the 128px or 256px icons for the sharpest results on most Android phones.

🍎 iOS (iPhone/iPad)

iOS doesn't allow free icon swapping, but you can fake it using Shortcuts:

Method — Shortcuts App (Built-in, Free)

  1. Open the Shortcuts app (pre-installed)
  2. Tap + to create a new shortcut
  3. Tap Add Action → search for Open App → choose your app
  4. Tap the three dots (⋯) top right → Add to Home Screen
  5. Tap the icon next to the name
  6. Choose Choose Photo and select your icon PNG
  7. Tap Add — it appears on your home screen!
iOS limitation: tapping the icon briefly shows the Shortcuts app before opening your app. This is an Apple restriction and cannot be avoided without jailbreaking.

Apply the Wallpaper on iPhone

  1. Save the mobile_iPhone wallpaper to your Photos
  2. Go to Settings → Wallpaper → Add New Wallpaper
  3. Choose the saved photo and set it

💻 Desktop (Windows / Mac / Linux)

Windows

  1. Right-click any desktop shortcut → Properties
  2. Click Change Icon
  3. Browse to the .ico or .png icon file
  4. Click OK
For .png files, use a free tool like IconChanger or CustomizerGod on Windows.

Mac

  1. Right-click any app in Finder → Get Info
  2. Click the icon in the top-left of the Info window
  3. Drag and drop your PNG icon onto it
  4. Done! ✅

Linux

Right-click any app shortcut → Properties → Icon → browse to PNG.
